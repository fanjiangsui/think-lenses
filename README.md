# 思考鏡頭 v2(PWA)

借哲學家的提問，把卡住的事想清楚。**預設是輕量模式**：點一個狀況，讀一個問題，最後只做一件小事，不用打字；想認真寫下來時，再進「深入思考」。純靜態網頁，無需後端、無需建置工具；手機與 Mac 都用瀏覽器開，可「加到主畫面」。紀錄只存在各裝置的瀏覽器裡，用備份檔在兩台裝置之間合併。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` / `style.css` / `app.js` | 介面與邏輯(原生 JS，無相依套件) |
| `data/philosophers.json` | A 層公共內容包(10 張鏡頭卡，v0.3.0) |
| `sw.js` | 離線快取 |
| `manifest.webmanifest`、`icons/` | 安裝到主畫面 |
| `tests/` | 內容檢查與端對端測試，見 `tests/README.md` |

## 測試

```bash
python3 -m pip install -r tests/requirements.txt && python3 -m playwright install chromium   # 只需一次
bash tests/run.sh
# 部署後測試網址： python3 tests/e2e.py --url https://<帳號>.github.io/think-lenses/
```

## 本機試跑

```bash
cd think-lenses
python3 -m http.server 8000
# 瀏覽器開 http://localhost:8000
```

不能直接雙擊 `index.html`：瀏覽器不允許 `file://` 讀取 JSON 與註冊 service worker。

## 部署(讓手機能開)

需要 HTTPS 的靜態託管。任選一個，把整個資料夾放上去即可(路徑都是相對的，放在子路徑也能運作)：

- GitHub Pages：建立 repo，上傳這些檔案，到 Settings → Pages 選分支。
- Cloudflare Pages / Netlify：拖曳資料夾部署。

各服務的現行步驟與條款，請以官方說明為準(我沒有查證最新版本)。

## 安裝到手機與 Mac

- iPhone：Safari 開啟網址，分享 → 加入主畫面。
- Android：Chrome 開啟，選單 → 安裝應用程式。
- Mac：直接用瀏覽器開即可。

## 兩台裝置怎麼同步

1. A 裝置：備份 → 「分享或儲存備份檔」，存到 iCloud 雲碟或用 AirDrop。
2. B 裝置：備份 → 「選擇備份檔」匯入。
3. 需要反向時再做一次。

匯入是**合併**：同一則紀錄比較 `updated_at`，較新的留下；刪除會以「墓碑」形式一起傳遞。沒有自動同步，也沒有任何資料離開你的裝置。

## 驗收步驟(5 分鐘)

1. 開首頁：看到 5 個白話入口，沒有任何輸入欄。
2. 點「不知道該選哪個」：立刻出現一個問題，畫面上只有一個主要按鈕「下一個問題」。
3. 按「換個角度」換一面鏡頭，再按「我想行動了」，看到「今天只做這一件事」。按「好，我來做」。
4. 把手機時間或資料改成隔天(或隔天再開)：首頁會問「上次的小行動，做了嗎？」，點「做了」。
5. 首頁最下方「深入思考」：走一次完整流程(類型、問題、鏡頭、結論)，重新整理後內容仍在。
6. 備份頁「下載備份檔」，到另一台裝置匯入，確認出現「新增 N 則」。
7. 關閉網路後重新開啟，仍可使用。
8. 「設定」頁：用密語匯出加密備份，到另一台匯入，輸入錯誤密語確認被拒絕。
9. 「設定」頁開啟 App 鎖，重新整理後應出現鎖定畫面，輸入 PIN 解鎖。
10. 「紀錄」頁按「整理」，勾選幾則刪除，10 秒內按「復原」。

## 更新內容

- 改 `data/philosophers.json`，並調高 `meta.version`。使用者下次開啟時會取得新內容(service worker 採 stale-while-revalidate，需開啟一次才會更新快取)。
- 新增或刪除檔案時，同步修改 `sw.js` 的 `ASSETS` 並調高 `CACHE` 版本號。
- 新鏡頭不需要改程式：配色以 id 自動產生(`app.js` 的 `LENS_COLORS` 可指定固定色)。

## 資料格式與原設計的差異

見 `DATA_MODEL.md` 最後一節。主要是每則紀錄多了 `updated_at`、`deleted_at`，`answers` 多了 `kind`。

## 輕量模式的刻意取捨

- 預設流程是「讀問題 → 點一下 → 做一件小事」，打字全部選填。
- 輕量模式只使用不排斥低落情緒的鏡頭(尼采、沙特、卡繆不進入)，也只使用較溫和的問題。這由內容檢查強制：卡片自己寫了「低落或自責時不宜」的鏡頭，不可標為 `quick_ok`。
- 「失去與無常」目前**不在輕量入口**：覆蓋較薄，問題的語氣也不適合直接丟給正在難過的人。仍可在深入思考使用。
- 小行動記下後，隔天起第一次打開會回訪一次(做了／還沒／不適合我)。

## 資料保護與刪除

「設定」頁(備份與保護)提供：

| 功能 | 做什麼 | 不做什麼 |
|---|---|---|
| 加密備份檔(預設開啟) | 用你輸入的密語，以 PBKDF2-SHA256(600,000 次)推導金鑰，再用 AES-256-GCM 加密。檔案內看不到任何明文，包含筆數 | 密語**不會被儲存**。忘記密語，該備份檔無法開啟，也沒有任何方法救回 |
| App 鎖(預設關閉) | 開啟 app 或離開一段時間後回來，要輸入 PIN 或密碼。PIN 只存加鹽雜湊。連續輸錯 5 次會暫時鎖住 | **這是遮罩，不是加密**：本機資料仍是明文。忘記 PIN 只能清除這台裝置的紀錄，再用備份檔還原 |
| 背景遮蔽(預設開啟) | 切到背景時蓋住畫面，避免多工切換畫面露出內容 | 實際效果依手機系統而定 |
| 刪除 | 「紀錄」頁的「整理」可勾選批次刪除；刪除後 10 秒內可「復原」；清空文字框就是刪掉那段想法 | 不會刪除**已經匯出的備份檔**，也不會刪除其他地方的副本 |

刪除是以「墓碑」傳遞到另一台裝置(只留 id 與時間，內容立即清空)。復原會產生比墓碑更新的時間，所以能蓋過已經傳出去的刪除。

**沒有帳號與密碼登入**：帳號需要伺服器，這個 app 是靜態網站、資料只在你的裝置上；加了帳號等於把最私人的想法放到別人的伺服器。

### 限制(請讀)

- 瀏覽器裡的紀錄是明文。有技術手段(開發者工具、直接讀取瀏覽器資料)的人，可以繞過 App 鎖。App 鎖擋的是「隨手點開」，不是有心人。
- 備份檔經過 iCloud、AirDrop、訊息時，請務必使用加密。
- PBKDF2 次數固定為 600,000：我沒有在舊手機上量測過耗時，若加密或解密太慢，告訴我，可調整。
- 加密與 PIN 驗證使用瀏覽器內建的 WebCrypto，需要 HTTPS(GitHub Pages 預設符合)。
- 部分瀏覽器(例如 iOS Safari)要求「分享」必須緊接著點擊發生。我的處理是密語輸入完成後先在背景加密，並在第一次被拒絕時提示再按一次。**這條路徑我沒有實機驗證**。
